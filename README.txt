STATIC VERSION
===============
This folder is a plain GitHub Pages site:
- index.html
- style.css
- script.js
- assets/

No React, Vite, npm or GitHub Actions is required.

Upload the contents of this folder to the repository root and select:
Settings -> Pages -> Deploy from a branch -> main -> /(root).

Note: the original project uses Firebase for authentication and products. This static conversion keeps the storefront UI and local basket/search/sort interactions, but Firebase-backed login, database products and checkout are not included.
